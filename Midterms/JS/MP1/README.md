## Project Overview

This application audits dataset quality from a CSV file.

It validates:
1. Missing values
2. Negative sales values
3. Invalid date formats
4. Duplicate records

The system requires the user to input the full file path of the dataset before processing.

## How to Run

1. Open the project folder.
2. Double-click run.bat.
 The batch file will:
  Launch the application window automatically

## How to Use the Program

Once the window opens:
Manually enter the full file path into the text field

Click Analyze.
The system will:
1. Validate the file
2. Process the dataset
3. Display a formatted Data Quality Report

If the file path is invalid or unreadable, a validation error message will appear.
